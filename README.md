## 📖 О проекте

**TGDisk** — это веб-приложение для хранения и обмена файлами, использующее Telegram API в качестве бэкенда. Все файлы хранятся в «Избранном» (Saved Messages) или приватных каналах вашего Telegram-аккаунта, а удобный веб-интерфейс в стиле Google Drive делает работу с ними максимально комфортной.

```
Браузер  ──▶  TGDisk (Express)  ──▶  Telegram API (GramJS)
                    │
                    └─ SQLite (метаданные, пользователи, ссылки, ключи)
```

Сервер выступает потоковым шлюзом — файлы **не хранятся** на диске сервера, а транслируются напрямую между клиентом и серверами Telegram. Локально остаётся лишь легковесная SQLite-база с метаданными.

## 🚀 Быстрый старт

### Требования

| Компонент | Версия |
|:----------|:-------|
| **Node.js** | 20 / 22 LTS или новее |
| **npm** | 9+ |

### Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/dr-kto/TGDisk.git
cd TGDisk

# 2. Установите зависимости
npm install

# 3. Создайте файл конфигурации
cp .env.example .env

# 4. Запустите
npm start
```

Откройте **http://localhost:3001** в браузере:

1. При первом запуске создайте учётную запись администратора.
2. Подключите аккаунт Telegram, указав `api_id` и `api_hash` (или выбрав пресет).
3. Войдите через **QR-код** или **код по номеру телефона**.

## ⚙️ Конфигурация (.env)

| Переменная | По умолчанию | Описание |
|:--|:--|:--|
| `PORT` | `3001` | Порт HTTP-сервера |
| `HOST` | `127.0.0.1` | Адрес прослушивания (рекомендуется `127.0.0.1` за реверс-прокси) |
| `SECRET` | *(авто)* | Секретный ключ для подписи cookie и токенов (≥ 64 hex-символа) |
| `PUBLIC_URL` | `http://localhost:3001` | Внешний URL для публичных ссылок (без `/` на конце) |
| `MAX_UPLOAD_BYTES` | `2147483648` | Макс. размер загружаемого файла (2 ГБ) |
| `SPLIT_PART_BYTES` | `2040109465` | Порог авторазделения на части (~1.9 ГБ) |
| `API_PRESETS` | — | Пресеты `api_id:api_hash,...` для экрана входа |

---

## 🔑 Получение api_id и api_hash

1. Перейдите на **[my.telegram.org](https://my.telegram.org)** и войдите в аккаунт.
2. Откройте раздел **API development tools**.
3. Заполните название приложения (любое).
4. Скопируйте **`api_id`** (число) и **`api_hash`** (строка).
5. Укажите их при подключении или в переменной `API_PRESETS` файла `.env`.
